| Research Question | Scientific question | Can an agent discover data-dependent precision allocation that reduces the delivered size of a fixed multimodal decision model while preserving its broader generative and visual abilities? The single reference is the released intact BF16 model B0. The target is at most 40% of its delivered inference weight bytes, with graded reward for intermediate compression under fixed quality and resource gates. Evaluation includes free numeric answers, executable Python and SQL, structured tool calls and image-grounded numeric/spatial outputs; only one sixth directly tests calibrated decisions. The research object is the relationship between calibration data, expert sensitivity, limited precision and cross-family behavior. |
| Research Question | Why this is scientific research rather than pure engineering optimization | Uniform quantization ignores unequal sensitivity across layers, experts and modalities. The agent changes practice calibration selection, clipping and bounded precision allocation, evaluates the materialized model, observes which family or calibration gate fails, and revises its hypothesis. Storage reduction is measured against the existing B0 under the same fixed runtime and workload. The supplied uniform INT4/group128 BQ recipe is an optional Work-produced ablation for interpreting precision allocation; it is neither the Solution baseline nor a required artifact. The reward measures compression under preservation constraints. B0 distribution distortion is a diagnostic, avoiding normalization by an unavailable compressed reference. |
| Research Question | Starting environment and artifacts | The package contains deterministic generators, all public splits with gold/PNGs, CPU oracles, tensor selection, accounting and a pinned B0 source interface. `taskkit/tensors.py` implements symmetric INT4/INT8 pack/dequant and BF16 conversion on CPU. B0 is the existing original upstream BF16 release. BQ is only an optional Work recipe: INT4/group128/ties-even/max-absolute scaling; no BQ checkpoint is required or claimed available. Trusted code reconstructs compressed candidates to BF16, then loads the same pinned backbone runtime used for intact B0. Local weight acquisition, ordinary model-loader integration and task-specific measurements remain post-acceptance preparation. No native four-bit execution, reduced resident GPU memory or speedup is claimed. |

| Evaluation | Fixed evaluation protocol | Six families: rational/integer arithmetic; restricted single-return Python checked on twelve inputs; SELECT SQL checked on three databases; exact tool JSON; 448×448 PNG chart/grid numeric/coordinate outputs; binary confidence. Counts: 1,152 practice, 288 development and 576 evaluation, equally divided by family and short/compositional difficulty. All 2,016 gold outputs pass CPU oracles. | Evaluation | Evaluation mode and input | Five families use native System 2 free generation with the System 1 adapter disabled, not answer-letter logits. Trusted prompts/templates specify greedy decoding, thinking disabled and at most 160 output tokens. Inputs are capped at 2,048 text tokens and one 448×448 image; generated gold answers fit the output budget. Invalid/truncated answers are incorrect. Each record has an exact oracle or executable checker. Only confidence records enable the unchanged System 1 interface and use binary labels. Probe probabilities use frozen oracle prefixes independently of generated answers. Judge runs one fixed model at a time. |
| Evaluation | Reward or score definition | Let A be macro correctness across six families; confidence correctness thresholds probability at 0.5. Let B be mean binary Brier loss, and r be delivered inference weight bytes divided by B0 bytes. Completed runs require A≥A0−0.01, each family accuracy≥its B0 value−0.03, B≤B0+0.01, r≤1, peak GPU allocation≤64 GiB, and warmed timing latency≤1.10×B0. Eligible score is `100 × clip((1−r)/0.60, 0, 1)`. Full score requires r≤0.40 and every gate; B0 has r=1 and score zero. Thus 40% is the full-score target, not an entry gate that makes all eligible models tie. For example, r=0.70 gives 50 points if all gates pass. Count every required delivered weight, scale, adapter and frozen/shared inference dependency once; metadata/docs are excluded. Ephemeral reconstructed BF16 derivatives are excluded from delivered bytes but their actual reconstruction time and memory are charged. Source originals of compressed experts are validation-only, never extra inference dependencies. Mean total-variation distance D from B0 over eighty probes is reported as a diagnostic only; no BQ measurement or nonzero-DQ condition is needed. Complete gate failures score zero; attributable compile failures, illegal memory access, crashes, invalid artifacts, timeout, infrastructure and incomplete runs are unscored. Every research attempt consumes the declared call budget. |
