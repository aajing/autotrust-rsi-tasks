# Native integration and admission contract

This package is a complete proposal/data/scoring contract, not a claim of a completed OpenRSI container or GPU execution. No upstream program was executed during drafting. Every scientific choice below is fixed; ordinary loader, accounting and `/tests/test.sh` integration is task-author work after acceptance.

1. Author setup checks out `AIoT-MLSys-Lab/SVD-LLM` at `7538cca98880ff312a79a16252aab5a7b480fbe9`, the fixed PyTorch/Transformers revisions in SOURCES.md, and downloads the existing Mistral release at `27d67f1b5f57dc0953326b2601d68371d40ea8da`. Use safetensors/config/tokenizer files only; preserve source/model/data licenses. Hash every delivered dependency and freeze the runtime/container once before scored research. 2. Solution only copies B0 and creates its all-dense identity map. It never decomposes, sparsifies, profiles, fits, trains or evaluates; there is no missing newly compressed baseline artifact. Task-author activation measures B0 once under the full fixed protocol, publishes its real reference record and binds it to data/runtime/source/device hashes. Scores remain unmeasured until that ordinary step.
3. All candidate construction, optional controls, profiling, local recovery and export occur in Work. At most one active recovery block and one GPU; host staging avoids full-model optimizer state. Extra source/library snippets may be edited in Work, but only allowed exported numeric tensors affect Judge inference.
4. Judge reloads the complete Work snapshot using the trusted loader below and fixed tests injected Judge-only. This is the current shared environment, not a future clean-Base verifier. No submitted model class, pickle, Python exporter or timing JSON is accepted as executed evidence. Normal Judge calls are candidate-only versus frozen B0 measurements.

## Existing source entrypoints and faithful task adaptation

`SVDLLM.py --step 1` supplies whitening/decomposition; `--step 2` supplies whitening plus sequential local update. `--model mistralai/Mistral-7B-v0.1`, `--run_low_resource`, `--whitening_nsamples`, `--updating_nsamples`, `--model_seq_len` and `--save_path` are actual source arguments. `evaluater.py` supplies source perplexity/efficiency evaluation. Do not pass the task retention fraction blindly to `--ratio`: the source main inverts it. The task uses explicit per-matrix ranks instead.

The fixed task adapter takes calibration batches from the materialized public selector, implements the source covariance whitening/SVD/local-update mathematics, and exports static factors. It replaces source random-window/cache behavior and pickle output with deterministic task data and safetensors. It does not need C4 Google Drive assets, PTB, gated Llama weights, LoRA datasets or source trust_remote_code. Native Mistral remains Transformers 5.7.0; the source’s whole custom attention class is not substituted into Judge. This avoids tying a new runtime to an untested older cache API.

Each selected native linear W[m,n] becomes task-owned `FactorLinear(U[m,r], V[r,n])` returning `linear(linear(x,V),U)`. Rank is a multiple of 8 and r(m+n)≤mn; dense mode loads the untouched source W. Seven eligible projection names ×32 layers gives 224 choices. Preserve biases (all selected source projections are bias-free), output dimensions, GQA, RoPE, norms, embeddings, head, attention masks and dtype. No UV dense product, dense residual, arbitrary activation hook or runtime rank switch is allowed. Count actual BF16 factor payloads and every frozen weight once; tensor metadata/document bytes are not model payload. Full score requires at least 40% total payload reduction plus all gates; quality attainability has not been measured.

## Fixed quality and timing execution

Quality: native BF16 Mistral, SDPA, eval/no_grad, no torch.compile. All 128 WikiText blocks produce exactly 65,536 scored causal tokens; accumulate loss in float64 on the host after stable per-token float32 log-softmax. Generate 256 GSM8K answers with the frozen two-shot prompts, greedy sampling, EOS stop and 256-token limit. Exact numeric parsing uses the last valid `#### <number>` marker; invalid outputs remain in the denominator.

Timing: six fixed bucket shapes, two distinct full batches per bucket, no KV cache, full-vocabulary logits. Token tensors are on GPU before timing. Perform two warmup passes and five complete measured passes with CUDA synchronization around each bucket. Include the whole forward (not selected GEMMs alone); exclude tokenizer/host transfer and one-time packing equally as specified, but charge those to Judge wall. Use median latency per bucket. Publish all five values, source/runtime/device fingerprint, actual allocated/reserved peak memory and throughput ratios. An untimed dispatcher/profiler check must not contaminate the reported timing loops. A dense sentinel moving more than 3% triggers an infrastructure drift check; unresolved drift is unscored. Repeats consume budgets/attempts as declared.

`scoring.py` is only arithmetic over operator-captured receipts; it cannot authenticate timings. Never use candidate-written outputs as official metrics. `test_scoring.py` uses explicitly synthetic fixtures, not model results.

## Accounting and failures

Work hard limit: 7,200 seconds, including construction/export/development. All full-model calls and block-local replays count their input plus produced output token positions toward 8,388,608 forward exposures; a sequence replayed through 32 blocks counts 32 times its length. Training separately counts 262,144 input-plus-target exposures, with repeated epochs charged, and at most 256 optimizer updates. Teacher forward production and subsequent training reuse each consume their corresponding counters. At most 512 distinct selected calibration records; generated variants inherit provenance and count. Retries, failed ideas and discarded outputs do not reset any candidate or trajectory clock. Check limits before each operation and fail closed on exhausted budgets.

Judge hard limit: 2,700 seconds including admission, loading/packing, full quality, timing repeats, drift checks and finalization. Candidate compile/error/illegal memory/crash and malformed artifacts are unscored; infrastructure/timeout/incomplete results are also unscored. Completed quality/resource gate failures get finite zero. Every attempted research call counts toward the sixteen-attempt trajectory cap. Default research time is 24 hours, with a 48-hour extension available; no paid GPU is provisioned by these files.
