| Research Question | Why this is scientific research rather than pure engineering optimization | Layer/head/MLP allocations interact with inherited representations and hardware utilization. | Evaluation | Fixed evaluation protocol | Text A: all 4,358 physical rows of WikiText-2-raw-v1 test, in source order; text B: first 2,048 nonempty <&#124;endoftext&#124;>-delimited stories of pinned TinyStories-valid.txt (actual full file has 21,990). Append EOS after each source item including blank WikiText rows, tokenize with pinned GPT2+native pad, concatenate per domain and create nonoverlapping windows at lengths 256,512,1024. Include the final window when it contains at least2 tokens; ignore only padding, no source resampling. Score next-token mean NLL separately for all six domain/context cells. H100 timed full-forward workloads are (batch,length)=(1,128),(4,512),(8,1024), using deterministic cyclic slices of these same token streams; all vocab logits are computed. Five rounds,25 warmup and100 timed forwards each workload, synchronized GPU wall time and median of round medians. Peak memory includes candidate weights plus workspace/output. Work max60min and10M training-token exposures per artifact; Judge max30min; mandatory overhead15min. Total24h default/48h extension. At most one infrastructure retry of an unchanged artifact, counted against wall time; no candidate-failure retry, item replacement or best-of measurement. Invalid structure, numerical NaN, compile/illegal-access error, crash, timeout or incomplete runs are unscored. Fully valid complete scientific-gate failures score0. |

| Evaluation | Reward or score definition | All six NLL cells must be <= their frozen B0+0.08 nats/token; each latency workload <=1.05x B0; peak allocated GPU memory <=1.05x B0; all parity/structure gates pass. Let s=canonical_stored_tensor_bytes/B0_bytes and r=geometric_mean of the three candidate/B0 latency ratios. Score=100*min(clip((1-s)/0.30,0,1),clip((1-r)/0.40,0,1)) if all gates pass, otherwise0 for a complete valid measurement. Full score requires s<=0.70 and r<=0.60 simultaneously. Invalid/incomplete outcomes have null score. B0 scores0. Targets are proposed and unvalidated: width/head/MLP interactions may make the full target unattainable at the quality tolerance; the benchmark does not claim a known optimum. |
