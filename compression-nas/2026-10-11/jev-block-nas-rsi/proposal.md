| Research Question | Scientific question | Can search over placement, module topology and weight sharing reduce the released detachable JEV-9B System 1 branch to at most 25% of its canonical FP32 tensor bytes while preserving native decision distributions and calibration across three primitives and thirteen disclosed domain families, with the original backbone and System 2 path unchanged? |
| Research Question | Why this is scientific research rather than pure engineering optimization | Compare depth-specific adaptation, nonlinear residual adapters, parallel branches and shared weights under the same frozen backbone, corpus and evaluation. Each experiment trains/exports a proposed graph, measures fidelity and resource cost, and revises a structural hypothesis. The objective is incremental capability-block storage, not a claim to compress the 9B backbone or substantially accelerate whole-model inference. It differs from Kev decision architecture (fresh 0.5B decision training), depth-width allocation (redistributing backbone capacity), and static MoE expert deletion. |

| Research Question | Files/components the agent may modify | Work research code and candidate artifacts only. Search optional projection LoRA at the ten released target module names, rank in {1,2,4,8,16,32}; add up to two residual modules after each of the 32 decoder blocks, each low-rank linear or SiLU bottleneck MLP, width in {8,16,32,64,128,256}; choose serial or parallel-with-sum composition and share equal-shape module weights across locations. | Evaluation | Fixed evaluation protocol | Use exactly 2,048 yuri_v3 rows per primitive from the pinned test_set_30k source, ordered by SHA256("jev-block-nas-rsi:v1:"+id), ties by original line ordinal; no resampling or duplicates. | Evaluation | Reward or score definition | All gates must pass: per-primitive KL(target&#124;&#124;p) <= B0+0.005 nats; per-family KL <= B0+0.010; per-primitive soft-ECE10 <= B0+0.005; choice argmax agreement >= B0-0.01; noul soft-target Brier <= B0+0.001; score RPS <= B0+0.003; every timing workload <=1.15 times frozen B0; peak allocated GPU bytes <=1.05 times B0; structural System 2 integrity. Then score=100*clip((1-branch_bytes/B0_branch_bytes)/0.75,0,1). Full score means <=25% branch bytes and all gates. KL is averaged per row; family KL mixes its rows equally; ECE and RPS exact definitions are in DATA.md. B0 scores zero. Invalid/incomplete/infrastructure outcomes have null score; valid complete scientific failures score zero. | Evaluation | Measures preventing reward hacking | Task-owned graph construction rejects cycles, undeclared ops, unsupported shapes, data-conditioned routers and uncounted tensors; branch generation cannot replace the trusted inference code. Hash all protected backbone/tokenizer/task assets. Trusted candidate and reference reports must have matching SHA256 data_manifest_sha256 and runtime_fingerprint; missing/different bindings are unscored. System 2 is guaranteed structurally by dispatching to the untouched backbone with every branch node disabled; validation additionally compares logits on 16 public probes. Soft labels are public and fit-able, so memorization through small weights remains possible and is disclosed. Metadata IDs/families are never passed to the model. Judge loads the actual submitted tensors, recomputes probabilities and bytes, and does not trust candidate reports. Shared snapshot limitations are explicit. |
| Evaluation | Noise handling and meaningful improvement | Quality uses fixed BF16 model execution, FP32 probability outputs and FP64 metric reductions. No stochastic generation contributes to the score. Use seed 20261010, five timing rounds and frozen hardware/software metadata. Timing interleaves 32 selected rows per primitive in a 96-row ring, with a continuous cursor across the 10 warmup and 30 measured batches of each round, separately for batch sizes 1 and 8; DATA.md defines the exact order. Report latency spread; if reference validation variation exceeds 5%, do not freeze a misleading reference: execution validation must stabilize the environment before opening research. No best-of retry selection. A positive score requires all quality gates plus genuine canonical byte reduction; 1 point represents 0.75% of B0 branch bytes. |
